What to alert me about

Thresholds

When receivables turn red, when a held deposit gets flagged for follow-up, how far ahead to default the next chase date. Sensible defaults are pre-filled; leave blank to reset a field.

Warehouse (route origin)

The address every route starts and ends at. Used by the route planner on /route.html. Saving geocodes the address to a lat/lng pin so the planner can measure real distances.

Test data

Seed a fixed set of Da Nang test customers + orders (1–3 crates and 1–2 jugs each) for previewing the today board, map, and route planner. Every doc is tagged testFixture: true and the cleanup button only touches those — real orders and customer records are never affected.

Drivers & loadouts

The container capacity each driver's truck holds on a standard run. The route planner uses this as a hard constraint — a route that overflows any container type is rejected before we spend routing quota on it. Leave a type at 0 if the truck never carries it.
